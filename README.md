# Uppgift 8

Man gör mycket som utvecklare. Man utvecklar inte bara, man testar, reviewar och provar sig fram. Ibland samtidigt. Då kan man behöva hoppa mellan flera olika brancher för att utveckla lite på någon annan feature i väntan på en review på en PR man har uppe, eller för att köra tester i en branch någon annan har gjort en PR på. Sitter man och utvecklar samtidigt som man ska bolla allt detta får man komma ihåg att stasha alla sina ändringar innan man byter branch, eller göra massa wip-commits hela tiden. För även om man öppnar samma repo i flera flikar i sin terminal kommer branchen bytas inte bara i den flik man jobbar, utan även alla andra flikar. Men det finns ett sätt att jobba i flera brancher parallellt! Enter worktrees.

Ett worktree är ett sätt att checka ut en branch i en ny katalog i sitt filsystem, som arbetar fristående och isolerat från den branch man står i i sitt vanliga repo. Så i praktiken är det ett sätt att checka ut flera branches samtidigt. För att skapa ett nytt worktree kör man kommandot `git worktree add <path> <branch>`. Om pathen man anger slutar med namnet på en branch som finns i repot, kan man skippa det sista argumentet. Ex. om det finns en branch som heter `feature` som man vill checka ut i katalogen ovanför den man står i, skriver man `git worktree add ../feature`. Om man sedan går till den katalogen kommer man lägga märke till att den är en kopia av repot man jobbar i, men att man är på branchen man namngav när man skapade worktreet, så ex. `feature`. För att lista alla worktrees man skapat kör man kommandot `git worktree list`, och för att ta bort ett worktree kör man kommandot `git worktree remove <path>`. Så för att fortsätta på det tidigare exemplet, skulle man köra kommandot `git worktree remove ../feature` för att ta bort worktreet när man är klar.

## Uppgift

Skapa ett worktree i valfri katalog i filsystemet från en valfri branch som finns i detta repo. Testa sedan att göra ändringar i något av de worktrees som nu finns och se vad som händer. Syns ändringarna i bägge worktrees? Kan man checka ut en annan branch i sitt worktree? Vad händer om man gör en ändring i ett worktree, stashar, och sedan poppar i det andra worktreet? Om du kommer på något mer som vore intressant att testa, kör på!
